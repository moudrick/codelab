# CodeLab

CodeLab is a desktop-agnostic devcontainer scaffold for secure pair and group coding
sessions (interviews, experiments, mentoring) across Linux, macOS, and Windows (via WSL).

## Kick start (30 seconds)

```bash
git clone https://github.com/your-org/codelab
cd codelab
code .
```

VS Code → **Reopen in Container** → choose a profile.

## Next step: Live Share

Once inside the container:
1. Open **Live Share** panel in VS Code
2. Start a collaboration session
3. Share the link with peers

Live Share is designed exactly for this workflow: shared editor, optional terminals,
optional debugging — all scoped to the container.
